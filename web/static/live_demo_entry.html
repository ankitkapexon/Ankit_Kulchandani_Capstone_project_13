Prerequisites Required For This Demo

Use Start / Restart Services first. The backend checks and reports missing setup items in the status panel below.

  • Python virtual environment with project dependencies installed.
  • Appium CLI available on PATH and startable on port 4723.
  • Android Platform Tools installed with adb available on PATH.
  • Android Emulator CLI available on PATH (or standard Android SDK location).
  • At least one Android AVD and system image available (backend can auto-create an AVD when tools/images exist).
  • LLM provider credentials (for example OPENAI_API_KEY or LiteLLM provider settings) must be set for non-mock generation.
